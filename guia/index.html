Em resumo

São sete pedidos de trabalho prontos para copiar: uma página de venda, um painel de vendas, uma apresentação, um explicativo animado, um editor de fotos, um jogo 3D e uma central de agentes. Cada pedido vem em três formas: para um agente que trabalha numa pasta (Claude Code, Codex, Cursor), para uma janela de chat (Agnes, ChatGPT, Gemini) e como briefing para uma pessoa, sem IA nenhuma. Serve para comparar modelos, escolher ferramenta ou treinar uma equipe. Os dados, o gabarito e o avaliador por script vêm junto; para usar basta copiar o texto, e para o avaliador, ter Python 3.

O que é

Uma prova, três jeitos de aplicar

O núcleo do pedido é igual nas três formas. Muda só o que a ferramenta consegue fazer: gravar arquivo, responder num chat ou ser feito à mão.

🗂️ Agente com pasta

Claude Code, Codex, Cursor, Antigravity, Gemini CLI, OpenCode. O agente lê os dados da pasta, grava os arquivos e escreve um ENTREGA.md contando o que fez.

💬 Janela de chat

Agnes, ChatGPT, Gemini, Claude.ai, DeepSeek, Grok, Copilot. Sem pasta: a resposta é um único HTML completo, e os dados já vão colados dentro do pedido.

🧑‍💼 Sem IA

O mesmo pedido como briefing para uma pessoa ou equipe, com tempo sugerido. Vale para aula, seleção de freelancer ou para comparar gente com máquina.

🖼️ Imagem é opcional

Se a ferramenta gera imagem ou vídeo (exemplo: Higgsfield, Agnes, Codex), ela usa. Se não gera, desenha em código. Nenhuma prova depende de gerador.

🎯 Armadilhas plantadas

O painel recebe dados sujos de propósito; a apresentação recebe anotações com preço que mudou, conta errada e número proibido.

📏 Nota sem IA

Um script confere o que dá para medir (total certo, número proibido, ferramentas presentes) e uma ficha de 10 pontos cobre o resto.

Como funciona

Preparar, rodar, conferir, comparar

Para uma comparação justa, cada concorrente recebe a mesma prova, na mesma forma, numa pasta própria.

Escolha a prova→ Escolha a forma→ Copie o prompt→ Concorrente trabalha sozinho→ kit/avaliar.py→ Ficha de 10 pontos

# Prova 1: Página de venda

Crie uma página de venda para uma marca de assinatura de café.

Você escolhe o nome da marca, os textos e o visual. A página tem um único objetivo: o visitante começar um teste grátis. Nenhum link pode tirar a pessoa desse caminho.

Crie um momento que faz a pessoa parar de rolar: uma cena (vídeo ou animação) comandada pela rolagem. Se a página não rolar, essa cena abre a página.

Arquivo principal: `index.html`. Tem que abrir com dois cliques.

## Capricho
- Faça ficar bonito de verdade: quem passar o olho tem que parar de rolar a tela.
- Use as ferramentas e habilidades que você tiver (design, animação, gerador de imagem). Você escolhe.

## Imagens e vídeo (opcional)
- Se você tiver um gerador de imagem ou de vídeo ligado (exemplo: Higgsfield, Agnes, Codex, um modelo local), use: no máximo 8 imagens e 1 vídeo curto, salvos como arquivo na sua pasta.
- Se não tiver, desenhe tudo em código (SVG, CSS, canvas). A prova vale igual.
- Modo raio-X: a tecla X e um botão pequeno ligam contornos, numa cor para cada imagem ou vídeo gerado e noutra cor para cada animação feita em código, com uma etiqueta pequena em cada um.

## Regras
- Trabalhe sozinho. Não faça perguntas. Termine de uma vez.
- Trabalhe só dentro da sua pasta.
- Salve tudo como arquivo na pasta. Não use arquivos da internet.
- Não publique, não faça deploy, não poste nada. Nunca toque som.
- No fim, escreva ENTREGA.md na pasta: o que fez, como abrir e cada imagem ou vídeo gerado (arquivo, o que mostra, que ferramenta fez).
