7 TESTS FOR ANY AI

The same request, presented the same way, to compare models, tools, or people. Includes an answer key and a script-based score.

See the 7 tests View on GitHub
In brief

Seven ready-to-copy work requests: a sales page, a sales dashboard, a presentation, an animated explainer, a photo editor, a 3D game, and an agent hub. Each request comes in three formats: for an agent that works in a folder (Claude Code, Codex, Cursor), a chat window (Agnes, ChatGPT, Gemini), and a brief for a person, with no AI. Use them to compare models, choose a tool, or train a team. The data, answer key, and script-based evaluator are included; to try a test, simply copy the text. The evaluator requires Python 3.

What it is

One test, three ways to run it

The core request is the same in all three formats. Only the tool’s capabilities change: it can save files, respond in a chat, or be completed by hand.

🗂️ Agent with a folder

Claude Code, Codex, Cursor, Antigravity, Gemini CLI, OpenCode. The agent reads the data in the folder, saves the files, and writes an ENTREGA.md describing what it did.

💬 Chat window

Agnes, ChatGPT, Gemini, Claude.ai, DeepSeek, Grok, Copilot. No folder: the response is one complete HTML file, with the data included in the request.

🧑‍💼 No AI

The same request as a brief for a person or team, with a suggested time limit. Use it for a class, freelancer selection, or comparing people with machines.

🖼️ Images are optional

If the tool can generate images or video (for example, Higgsfield, Agnes, or Codex), it can use that ability. Otherwise, it can draw with code. No test depends on an image generator.

🎯 Deliberate pitfalls

The dashboard gets deliberately messy data; the presentation gets notes containing a changed price, a wrong calculation, and a number that must not be used.

📏 Score without AI

A script checks what can be measured (correct total, forbidden number, required tools), and a 10-point scorecard covers the rest.

How it works

Set up, run, check, compare

For a fair comparison, each participant gets the same test in the same format, in a separate folder.

Choose a test→ Choose a format→ Copy the prompt→ Participant works independently→ kit/avaliar.py→ 10-point scorecard

# Challenge 1: Sales page

Create a sales page for a coffee subscription brand.

You choose the brand name, copy, and look. The page has one goal: get the visitor to start a free trial. No link can take them away from that path.

Create a moment that makes people stop scrolling: a scene (video or animation) controlled by scrolling. If the page doesn't scroll, that scene opens the page.

Main file: `index.html`. It must open with a double-click.

## Polish
- Make it truly beautiful: anyone glancing at it should stop scrolling.
- Use the tools and skills you have (design, animation, image generator). You choose.

## Images and video (optional)
- If you have an image or video generator connected (for example: Higgsfield, Agnes, Codex, a local model), use it: at most 8 images and 1 short video, saved as files in your folder.
- If you don't, draw everything in code (SVG, CSS, canvas). The challenge counts just the same.
- X-ray mode: the X key and a small button turn on outlines, using one color for each generated image or video and another for each animation made in code, with a small label on each one.

## Rules
- Work alone. Don't ask questions. Finish in one go.
- Work only inside your folder.
- Save everything as files in the folder. Don't use files from the internet.
- Don't publish, deploy, or post anything. Never play sound.
- At the end, write ENTREGA.md in the folder: what you made, how to open it, and each generated image or video (file, what it shows, which tool made it).

For a chat window (Agnes, ChatGPT, Gemini, Claude.ai, DeepSeek, Grok, Copilot)

# Challenge 7: Agent command center

Create a command center for a small team of AI agents: a planner, a researcher, a writer, and a reviewer.

I type a goal and watch the team plan, work, and review in real time. I can pause or stop a run. At the end, I get a clean report and can open past runs. If an agent fails, I can see why and the run continues.

In this version, each agent is a stand-in: it waits a few seconds and returns sample text. Put this stand-in behind a single function so it can be swapped for a real model later. Don't use an API key.

Main file: `central.html`, which opens with a double-click. If you need a server, it must start with a single command listed in ENTREGA.md. Test before saying you're done.

## Polish
- Make it truly beautiful: anyone glancing at it should stop scrolling.
- Use the tools and skills you have (design, animation, image generator). You choose.

## Images and video (optional)
- If you have an image or video generator connected (for example: Higgsfield, Agnes, Codex, a local model), use it: at most 8 images and 1 short video, saved as files in your folder.
- If you don't, draw everything in code (SVG, CSS, canvas). The challenge counts just the same.
- X-ray mode: the X key and a small button turn on outlines, using one color for each generated image or video and another for each animation made in code, with a small label on each one.

## Rules
- Work alone. Don't ask questions. Finish in one go.
- Work only inside your folder.
- Save everything as files in the folder. Don't use files from the internet.
- Don't publish, deploy, or post anything. Never play sound.
- At the end, write ENTREGA.md in the folder: what you made, how to open it, and each generated image or video (file, what it shows, which tool made it).

How to run · step by step

From setup to score

Choose the path that fits your tool. Steps 1 and 5 apply to everyone.

1

Download the kit

To copy the prompts, this page is enough. To prepare folders and evaluate: Python 3 and, ideally, Chrome or Chromium (the checker opens the page hidden to read the numbers the JavaScript calculates). No git? Use the "Code › Download ZIP" button on GitHub and unzip it. File names (apresentacao.html, painel.html) and the CSV columns stay in Portuguese on purpose: the checker looks for them.

git clone https://github.com/inematds/sete-provas-ia
cd sete-provas-ia
2

Agent with a folder: prepare one folder per participant

The script copies the prompt (PROMPT.md) and the data required by the test. Format: preparar.py <test> <folder> [agente|pessoa] [pt|en|es]; type the words agente and pessoa exactly like that (they are Portuguese), and add en to get the English prompt. On Windows, use py instead of python3. Then open the agent in the folder and paste in PROMPT.md.

python3 kit/preparar.py 2 corrida/claude/02 agente en    # test 2 for Claude Code
python3 kit/preparar.py 2 corrida/codex/02 agente en     # the same test for Codex
cd corrida/claude/02 && claude              # paste the contents of PROMPT.md; then go back with cd ../../..
3

Chat window (Agnes, ChatGPT, Gemini…)

Copy the “For chat window” tab from the test and paste it into a new conversation. The response is a complete HTML file: copy the block into a file with the requested name (e.g., apresentacao.html) and open it with a double-click.

No terminal (Windows or Mac): open Notepad (on Mac, TextEdit with "Format › Make Plain Text"), paste the HTML, choose "Save As", pick "All files", UTF-8 encoding, and save as apresentacao.html. Double-click the file and it opens in the browser.

# with a terminal (Linux/Mac), the same in two lines:
mkdir -p corrida/agnes/03 && nano corrida/agnes/03/apresentacao.html
With Agnes: if you request images during the conversation, describe the image in English and keep any text within it brief; image requests in languages other than English are often blocked by the filter. If the response is cut off, ask “continue exactly where you left off” and combine the parts before saving. The chat format was tested with Claude Sonnet; it has not yet been evaluated with Agnes or other chat tools.
4

No AI: give them the brief

Prepare the folder in the “person” format and give it to the person doing the work. The brief includes a suggested time limit and explains how the result will be evaluated.

python3 kit/preparar.py 3 corrida/maria/03 pessoa en   # PROMPT.md + notas.txt
5

Check the work and score it

The checker prints OK, AVISO (warning) or FALHA (fail) for each measurable item; its messages are in Portuguese. Without Chrome or Chromium it reads only the code, and numbers the page calculates by itself become AVISO (check them on screen). Then open the file, use it for 5 minutes, and fill out the scorecard.

python3 kit/avaliar.py 2 corrida/claude/02            # agent submission
python3 kit/avaliar.py 3 corrida/agnes/03 --chat      # chat submission (no ENTREGA.md)
Evaluate without AI

The answer key can be checked by hand

The data is generated by a script with a fixed seed, so the correct answer is always the same. You can check it with a calculator.
